# CodeAlpha Task 2: Temperature Alert System

## Project Overview
The Temperature Alert System is an IoT-based project designed to monitor temperature and provide an alert when the temperature exceeds a predefined threshold. The system uses a temperature sensor, an LED, and a buzzer to indicate high-temperature conditions.

## Objectives
- Monitor temperature using a sensor.
- Detect when the temperature exceeds the set threshold.
- Activate an LED and buzzer to provide an alert.
- Understand the basic principles of IoT and sensor-based monitoring.

## Components Used
- Arduino Uno
- Temperature sensor
- LED
- Buzzer
- Breadboard
- Jumper wires

## Working Principle
The temperature sensor measures the surrounding temperature and sends readings to the Arduino. The Arduino compares the measured temperature with a predefined threshold. When the temperature exceeds the threshold, the LED and buzzer are activated. Otherwise, the alert remains off.

## Tools Used
- Tinkercad Circuits
- Arduino C/C++ programming

- Normal temperature: LED and buzzer remain off.
- High temperature: LED and buzzer turn on.
